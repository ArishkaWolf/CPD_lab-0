# CPD Lab 0

Лабораторная работа 0 по кросс-платформенной разработке.

## Вариант

Вариант 5:

`F(x) = x * cos(x)`

Метод численного интегрирования:

`Left Riemann Sum`

## Описание

Приложение позволяет ввести две границы интервала интегрирования и количество точек прямо на странице, после чего вычисляет приближенное значение интеграла функции `F(x) = x * cos(x)` методом левых прямоугольников.

Функция интегрирования принимает интегрируемую функцию как параметр.

Количество точек интегрирования: `10000`.

## Запуск

Откройте `index.html` в браузере.

После запуска нужно заполнить:

1. начало интервала;
2. конец интервала.

Результат вычисления будет показан на странице.
