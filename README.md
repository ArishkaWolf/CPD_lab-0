# CPD Lab 0

Лабораторная работа 0 по кросс-платформенной разработке.

## Вариант

Вариант 5:

`F(x) = x * cos(x)`

Метод численного интегрирования:

`Left Riemann Sum`

## Описание

Приложение запрашивает у пользователя две границы интервала интегрирования через `prompt`, после чего вычисляет приближенное значение интеграла функции `F(x) = x * cos(x)` методом левых прямоугольников.

Функция интегрирования принимает интегрируемую функцию как параметр.

Количество точек интегрирования: `10000`.

## Запуск

Откройте `index.html` в браузере.

После запуска нужно ввести:

1. начало интервала;
2. конец интервала.

Результат вычисления будет показан в окне `alert`.
